# Flight Change Policy — SkyBridge Airlines

## Standard Change Fees
- Basic Economy: $75 change fee plus any fare difference.
- Economy: $50 change fee plus any fare difference.
- Premium Economy and Business: No change fee; fare difference may still apply.

## Same-Day Changes
Same-day flight changes are available starting 24 hours before departure for a flat $25 fee, subject to seat availability in the same cabin.

## Name Changes
Full name corrections of up to 3 characters (e.g., typo fixes) are free. Full name changes to a different passenger are not permitted; a new ticket must be purchased.

## Weather and Airline-Initiated Changes
No change fee applies if SkyBridge cancels, delays, or reschedules the original flight.
